## Phase 6: Fix Missing Source Code in Releases

### 6.1 Why 0.1.5 Missing Source Code vs 0.1.4
**Root Cause:** The `.github/workflows/release.yml` doesn't generate source archives.

**Current (lines 111-114):**
```yaml
files: |
  ${{ steps.artifacts.outputs.setup }}
  ${{ steps.artifacts.outputs.portable }}
  SHA256SUMS.txt
```

**Missing:** Source code zip/tar.gz that GitHub auto-generated in older releases

### 6.2 Update release.yml - Add Source Archives Step
**File:** `.github/workflows/release.yml`

**Add before "Create GitHub Release" step:**
```yaml
- name: Create source archives
  shell: pwsh
  run: |
    $tag = "${{ github.ref_name }}"
    # Create zip archive
    git archive --format=zip -o "Source-code-${tag}.zip" HEAD
    # Create tar.gz archive  
    git archive --format=tar.gz -o "Source-code-${tag}.tar.gz" HEAD
    Write-Host "Created source archives"
    Get-ChildItem "Source-code-*" | Select-Object Name, Length
```

### 6.3 Update release.yml - Include Source in Release
**Update files section (lines 111-114):**
```yaml
files: |
  ${{ steps.artifacts.outputs.setup }}
  ${{ steps.artifacts.outputs.portable }}
  SHA256SUMS.txt
  Source-code-*.zip
  Source-code-*.tar.gz
```

## Phase 7: Add Electron Build to CI (Optional but Recommended)

### 7.1 Current State
- Electron builds are done **manually** on your machine (hence 705MB)
- CI only builds Tauri (14-20MB)
- Your release shows both but CI doesn't produce Electron

### 7.2 Add Electron Build to release.yml
**Add after "Build Tauri app" step:**
```yaml
- name: Build Svelte frontend for Electron
  run: bun run build

- name: Build Electron app
  run: |
    cd electron-app
    npm ci
    npm run dist
    cd ..

- name: Collect Electron artifacts
  id: electron_artifacts
  shell: pwsh
  run: |
    $tag = "${{ github.ref_name }}"
    $electronSetup = Get-ChildItem "electron-app/dist-installer/*Setup.exe" | Select-Object -First 1
    $electronPortable = Get-ChildItem "electron-app/dist-installer/*Portable.exe" | Select-Object -First 1
    
    $setupName = "NanoPrayReminder-Electron_${tag}_x64-setup.exe"
    $portableName = "NanoPrayReminder-Electron_${tag}_x64-portable.exe"
    
    Copy-Item $electronSetup.FullName $setupName
    Copy-Item $electronPortable.FullName $portableName
    
    echo "electron_setup=$setupName" >> $env:GITHUB_OUTPUT
    echo "electron_portable=$portableName" >> $env:GITHUB_OUTPUT
```

### 7.3 Update Release Files
```yaml
files: |
  ${{ steps.artifacts.outputs.setup }}
  ${{ steps.artifacts.outputs.portable }}
  ${{ steps.electron_artifacts.outputs.electron_setup }}
  ${{ steps.electron_artifacts.outputs.electron_portable }}
  SHA256SUMS.txt
  Source-code-*.zip
  Source-code-*.tar.gz
```

**Note:** Phase 7 only works AFTER Phase 1-5 fix the electron-app bloat issue.
